What it does

Built from real operator pain: restarts that lose chunks, plugin updates that break the server, and staff who need access without shell keys. The demo exercises each of these.

⚡

Chat countdown, save-all, backup, kick verification and restart — run on demand or on a schedule with overlap prevention.

⌖

RCON console & live map

Audited console with persistent latest.log following, plus your BlueMap, Dynmap or Squaremap embedded right in the dashboard.

◇

Plugin & mod quarantine

Inventory plugins/ and mods/, quarantine a bad update, restore it, and edit configs with a diff review before saving.

♟

Players & moderation

Roster, kick, ban, op/deop and whitelist, chat moderation and Discord relay — every action attributed to an account.

World folder backups with retention, confirmed restore and wipe, cron or simple schedules, and pre-restart warnings.

Player portal & donations

Architecture

The public web app never touches RCON, world files or the server process. Work is queued through the control plane and executed locally by a paired agent.

 ┌──────────────────────────── CONTROL PLANE ─────────────────────────────┐
 │  Next.js UI ◄─► NestJS API + WebSocket ◄─► PostgreSQL · Redis/BullMQ   │
 └──────────────┬──────────────────────────────────────┬──────────────────┘
        HTTPS / WS │                                     │ job queue · heartbeat
                   ▼                                     ▼
 ┌──────────────── HOST (Go agent) ───────────────────────────────────────┐
 │ one-time pairing · versioned heartbeat · job runner · MC adapter       │
 │              └────►  Minecraft server (RCON · process · files)         │
 └─────────────────────────────────────────────────────────────────────────┘

1 · Click

Staff triggers an action in the dashboard.

2 · Authorize

Role checked; job enqueued per server.

3 · Execute

Agent runs it locally via the Minecraft adapter (RCON, process, filesystem).

4 · Audit

Output and initiating account return to the UI.

Engineering highlights

Decisions that matter beyond the feature list.

Security by design

Salted scrypt password hashing, persistent login throttling, JWT agent identity with key rotation, encrypted integration secrets, signed Stripe webhooks, and a documented security audit.

Reliable job pipeline

BullMQ queues with serialized mutations, bounded read concurrency, jittered retries, stale-run recovery, backpressure and overlap prevention for scheduled work.

RCON stays private

RCON binds to localhost or a private network and is never exposed to the public web app. World wipe and restore require explicit confirmation payloads.

Documented & maintained

Architecture, ERD, release context and design docs per feature, a protected main branch, PR templates and a detailed changelog.

Run it yourself

Requires Docker, Node 20, pnpm 9 and Go 1.22. Enable RCON in server.properties on the game host.

  1. Clone and configure
    git clone https://github.com/248Tech/Mastermind-Minecraft-Server-Manager.git
cd Mastermind-Minecraft-Server-Manager
cp infra/.env.example infra/.env
# set JWT_SECRET, JWT_AGENT_SECRET, BOOTSTRAP_ADMIN_EMAIL, BOOTSTRAP_ADMIN_PASSWORD
  2. Start everything
    make up
  3. Sign in at http://localhost:3000, then pair a host from Hosts → Pair.
